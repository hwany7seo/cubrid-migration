************
Migration Progress
************

A page where you can monitor the migration progress.

.. image:: ./image/migration_progress.png

========
vertex
========

Displays the table names from the source DB, the number of vertices extracted from each table, and the progress status.

========
Edge
========

Displays the FK and join table edges extracted from the source DB, along with their names, start vertices, and end vertices.

=============
Console View
=============

Displays the progress status. If a migration fails during the process, the content is displayed in red.
