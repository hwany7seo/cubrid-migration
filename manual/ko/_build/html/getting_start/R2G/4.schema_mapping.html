스키마 맵핑 페이지¶

스키마 선택 및 변경¶

원본 DB의 스키마 중에 이관하고싶은 스키마를 선택하는 페이지이다. 권한이 있는 스키마 목록이 표시되며, 현재 CoraDB는 멀티 스키마 지원하지 않으므로 단일 스키마로만 이관이 가능하다.

Update Database Objects¶

해당 버튼을 통해 변경된 객체 정보를 다시 로드하여 표시한다.
